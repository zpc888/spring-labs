RequestBodyAdvice cheat sheet

Compressed reference for the Spring MVC request-body read path inside a Spring Boot application.

Where it sits

  1. DispatcherServlet dispatches to the chosen handler.
  2. RequestMappingHandlerAdapter uses RequestResponseBodyMethodProcessor for @RequestBody.
  3. AbstractMessageConverterMethodArgumentResolver.readWithMessageConverters(...) selects an HttpMessageConverter.
  4. RequestResponseBodyAdviceChain.beforeBodyRead(...) can wrap the raw HttpInputMessage.
  5. The converter deserializes bytes into the target object.
  6. RequestResponseBodyAdviceChain.afterBodyRead(...) can inspect or replace the object.
  7. Bean validation runs afterward if the parameter has @Valid or @Validated.

Hook guide

Hook Best for Bad fit
supports Narrowing by parameter, target type, or converter type Doing work; keep it as a cheap predicate
beforeBodyRead Decrypting, signature checks, wrapping the input stream, raw-body logging Object-level validation; no Java object exists yet
afterBodyRead Inspecting or augmenting the deserialized object Raw-byte work; the converter already consumed the stream
handleEmptyBody Supplying defaults or rejecting empty payloads consistently Normal non-empty requests

Decision rule

If you need... Prefer...
Endpoint-agnostic security or auth Security filters / Spring Security chain
Controller-aware request-body transformation RequestBodyAdvice
Semantic bean validation after deserialization @Valid, validators, or binder validation
Cross-cutting metadata enrichment based on request body and handler parameter afterBodyRead

Important internals

  • Advice is applied only after a compatible converter is found.
  • Multiple advice beans can chain: each matching bean runs in order.
  • @ControllerAdvice can scope by annotations, packages, or assignable types.
  • @RequestBody is for body content, not form parameters.
